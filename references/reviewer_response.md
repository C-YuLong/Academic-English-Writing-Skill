# Reviewer Response and Revision Reference

Use this file for rebuttals, response letters, camera-ready revisions, and replies to reviewer comments.

## Response Structure

For each comment, use:

`Comment [R1-C1]: [short paraphrase or quoted reviewer comment]`

`Response: Thank you for the comment. [Direct answer]. [Evidence or clarification]. [Manuscript change].`

`Change: We have revised [Section/Figure/Table/page] to [specific change].`

Do not over-apologize. Be polite, direct, and evidence-based.

## Tone

- Acknowledge the reviewer concern.
- Explain the paper's intent and scope.
- Avoid defensive language.
- Avoid claiming the reviewer misunderstood unless necessary.
- Do not attack prior work or reviewer assumptions.
- If the reviewer is correct, state the revision clearly.
- If the reviewer is not fully correct, clarify the scope with evidence.

## Good Response Moves

Use these patterns:

- `We agree that [issue] was not sufficiently clear in the original manuscript. We have revised Section [x] to clarify [point].`
- `The proposed method is designed for [scope], rather than [out-of-scope scenario]. We have added this clarification to Section [x].`
- `To address this concern, we added [experiment/analysis/discussion]. The new results show [result].`
- `The baseline was selected because [reason]. We have now explained this selection in Section [x].`
- `We have corrected the terminology throughout the manuscript.`

## When Experiments Are Requested

If the reviewer asks for new experiments:
1. Decide whether the experiment is feasible and in scope.
2. If done, report setup and result.
3. If not done, explain why and provide alternative evidence if available.
4. Avoid promising future work unless it is truly outside scope.

## Camera-Ready Tracking

For camera-ready changes:
- Number reviewer comments.
- Track which manuscript changes address which comment.
- Ensure every reviewer concern has a response.
- Ensure terminology changes are applied globally, not only in one paragraph.
- Remove internal revision markers before final submission.
